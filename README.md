# 📚 Хичээл — Хятад, Англи хэл сурах вэб сайт

Монгол хэл дээрх хятад (HSK) болон англи (IELTS) хэл сурах платформ.

## Боломжууд

- **Бүртгэл / Нэвтрэх** — бүртгүүлэх, нэвтрэх, гарах, нэр болон нууц үг солих, бүртгэл устгах
- **Хятад хэл**
  - **HSK 2.0 (хуучин)** — 1–6 түвшин
  - **HSK 3.0 (шинэ)** — 1–6 болон 7–9 түвшин, 2.0-той харьцуулсан хүснэгт
  - Үг (ханз, пиньинь, монгол, англи), дүрэм + шалгах асуулт, өгүүлбэр
- **Англи хэл (IELTS)** — CEFR A1–C1, IELTS band оноотой харьцуулалт, үг, дүрэм, унших дасгал, шалгалтын зөвлөгөө
- **Сонсгол** — үг сонсох, өгүүлбэр сонсох, өгүүлбэрийн утга, сонсоод бичих (хурдыг тохируулна)
- **Тоглоом** — картаар цээжлэх, хос тааруулах, 60 секундийн хурдны сорил, өгүүлбэр байгуулах
- **Тест шалгалт** — 15 асуулт, 10 минут, 60%-иар тэнцэнэ, дүнгийн түүх хадгалагдана
- **Толь бичиг** — ханз, пиньинь (аялгуугүй ч болно), англи, монголоор хайх; дуудлага сонсох; «Миний үгс»
- **Хянах самбар** — XP оноо, дараалсан өдөр, цээжилсэн үг, түвшний ахиц

## Ажиллуулах

Сервер, суулгац шаардлагагүй. `index.html` файлыг хөтөч дээр нээхэд л болно.
Эсвэл локал сервер:

```bash
npx http-server .
# эсвэл
python3 -m http.server 8000
```

GitHub Pages дээр байршуулахдаа: **Settings → Pages → Branch** сонгоод хадгална.

## Бүтэц

```
index.html
css/style.css
js/data/hsk2.js           HSK 2.0 үгс
js/data/hsk3.js           HSK 3.0 үгс
js/data/chinese-extra.js  Хятад дүрэм, өгүүлбэр
js/data/ielts.js          IELTS үг, дүрэм, өгүүлбэр, унших дасгал
js/core.js                Бүртгэл, хадгалалт, дуу хоолой
js/quiz.js                Асуулт үүсгэгч
js/games.js               Тоглоомууд
js/app.js                 Хуудсууд, чиглүүлэгч
```

Шинэ үг нэмэхдээ `js/data/` доторх файлын тохирох түвшинд мөр нэмнэ үү.

## Анхаарах зүйл

- Бүртгэл болон ахиц **хөтчийн localStorage**-д хадгалагдана (сервергүй). Өөр төхөөрөмж дээр
  нэвтрэхэд мэдээлэл дамжихгүй. Олон хэрэглэгчтэй бодит сайт болгохын тулд backend
  (жишээ нь Firebase, Supabase) холбох шаардлагатай.
- Дуудлагыг хөтчийн Web Speech API уншина. Chrome / Edge / Safari-д хятад, англи дуу хоолой байдаг.
- Үгсийн жагсаалт нь түвшин бүрийн **төлөөлөх жишээ үгс** бөгөөд албан ёсны бүрэн жагсаалт биш.
